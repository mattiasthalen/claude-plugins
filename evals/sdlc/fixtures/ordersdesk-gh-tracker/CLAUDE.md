# ordersdesk

The shop's back-office order book. `README.md` has the commands.

## Tracking work

- Stories are tracked as GitHub Issues in this repository, one issue per story, labelled `story`.
- When a spec is approved, file it as a GitHub issue in this repository, labelled `spec`, with the spec as its body and linked to its story issue(s) by a `Refs #<n>` line for each.
