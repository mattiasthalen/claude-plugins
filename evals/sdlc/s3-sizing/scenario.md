# S3 — Sizing

Two ends of size (A18, ported from `delivery`). An epic of four independent features is refused as one delivery: the run names the parts and asks which one to take through the SDLC. A tiny change the requester says needs no interview skips it, but still gets a spec with checks and a preservation criterion, and still stops at the spec gate.

**Fixture:** `ordersdesk`.

| Case | Starts from | Graded |
|---|---|---|
| `epic` | a four-part intent | names the parts, asks which; no interview, no spec, no repo writes |
| `small` | "tiny, no interview needed" | no interview; `spec.md` in the docs dir with checks and a preservation criterion; no plan, no repo writes, no test-writer; stops at the spec gate with the seam choice |
