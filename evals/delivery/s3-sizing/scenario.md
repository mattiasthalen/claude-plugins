# S3 — Sizing

Two ends of size. An epic of four independent features is refused as one delivery: the run names the parts and asks which feature to deliver. A tiny change the requester says needs no interview skips it, but still gets a plan with a brief and checks.

**Fixture:** `ordersdesk`.

| Stage | Starts from | Graded |
|---|---|---|
| `epic` | a four-part request | names the parts, asks which one; no interview, no plan, no writes |
| `small` | "tiny, skip the interview" | no interview; a plan with a brief, guardrails and checks; no writes |
