# Lexicon

The words someone needs defined to talk about using or developing this marketplace's plugins. A term earns an entry only if it is language rather than code, needs defining beyond its ordinary meaning, and is the one word for its concept.

**small change** — A change the requester has called small, in their own words. It skips the intent and design steps and starts at tests first. Only the requester makes a change small; the flow never proposes or asks it.

**story** — One independently useful outcome of a request, written as "As a … I want … so that …", with acceptance criteria and a disposition. Each criterion is *stated* (the requester said it) or *proposed* (Claude filled it in, with why). The disposition is *now* (delivered in this change), *later* (kept as a scope fence) or *drop* (kept with a one-line reason so it does not come back). Two outcomes that cannot ship without each other are one story.
